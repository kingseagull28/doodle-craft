# Changelog

## 1.1.0 (2026-10-15)
* Added TNT (5 Gunpowder and 4 Sand in a checkerboard, Java 1.21 recipe) and Minecart with TNT.
* Gunpowder now comes from the Clockwork Room (tier 4) instead of the Moonlit Chamber.
* New bonus challenge: Big Red Block.
* Saved games automatically receive new supplies added to areas they already opened.

## 1.0.0 (2026-10-14)
* First release: 539 items, 482 recipes, 56 quests, 8 areas, 6 tiers, Creative Sandbox.
* Saved games survive updates that retire an item (unknown entries are dropped on load; imports stay strict).
* Builds to `docs/` for GitHub Pages.
